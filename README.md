# `voice_among_voices`

This is the code for Voice among Voices.

Use the scripts in the scripts folder to run locally or deploy to mainnet after starting dfx. Be sure to adjust the identity parameter for it to work (you can probably just remove it).

To run the frontend locally, use `npm run dev`. If you change anything about the interface in the backend, `npm run prebuild` will be your friend.

To deploy a token, run the script in the vav_evm folder, feed the address you get out into a .env in there and run again.

Have fun!
